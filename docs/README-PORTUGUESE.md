## 📖 O que é a Deborah?

Deborah é um bot de Discord com inteligência artificial projetado para responder perguntas sobre o cristianismo e a Bíblia, fornecendo insights bíblicos e orientações teológicas. ❤️

Convide-a para seu servidor [clicando aqui](https://discord.com/oauth2/authorize?client_id=1253330383475572768&permissions=8&integration_type=0&scope=bot).

---

## 🚀 Como usar?

### 🔹 Comandos e Funcionalidades:

<details>
  <summary><strong>📌 Comando: /ask</strong></summary>
  
  O comando `/ask` é ideal para perguntas simples e diretas. Ao utilizá-lo, a Deborah fornecerá uma resposta objetiva baseada na Bíblia.
  
  ![Ask Command](https://github.com/user-attachments/assets/b48f2fa4-2c07-43b2-a85b-cced708b5fe5)
  
  A resposta será enviada diretamente no chat onde o comando foi usado, sendo visível para todos os participantes.
  
  ![Response Example](https://github.com/user-attachments/assets/60e4837a-0876-4df2-8eac-32cec6b1c9f0)
  
  🔹 **Nota:** Diferente do `Chat IA`, a Deborah não mantém memória das perguntas anteriores. As respostas são curtas e objetivas.
</details>

<details>
  <summary><strong>⚙️ Comando: /config</strong></summary>
  
  🔹 **Nota:** Apenas administradores podem usar este comando.
  
  O comando `/config` permite configurar a Deborah conforme as preferências do servidor.
  
  ![Config Command](https://github.com/user-attachments/assets/c1d79df6-1c8f-4251-ae97-0cf41902c53f)
  
  Ele possibilita:
  - Definir quais canais permitem o uso dos comandos da Deborah.
  - Configurar quais cargos podem utilizar os comandos.
  - Determinar onde os `Chat IAs` serão criados.
</details>

<details>
  <summary><strong>💬 Chat IAs</strong></summary>
  
  🔹 **Nota:** Para criar um `Chat IA`, use o comando `/config` e selecione a opção `Criar painel de Chat`.
  
  Ao criar um `Chat IA`, uma thread será aberta e a Deborah guiará você até lá.
  
  ![Chat IA](https://github.com/user-attachments/assets/8efd8f77-b257-491a-9dd2-41b484f1aadd)
  
  Dentro da thread, você pode fazer perguntas e receber respostas diretamente.
  
  ![Chat IA Example](https://github.com/user-attachments/assets/b57112d2-86fa-4b0e-aa71-1e38a87bb22e)
  
  A principal vantagem do `Chat IA` é que a Deborah mantém memória das perguntas anteriores, tornando a conversa mais fluida.
  
  ![Chat Memory](https://github.com/user-attachments/assets/824b3e16-17b1-4e82-bb12-0a9df9b32360)
  
  🔹 Os `Chat IAs` são privados. Apenas o usuário que criou o chat, administradores e convidados mencionados no chat podem acessá-lo.
</details>
